# موقع شاليه كنف

موقع تعريفي ثابت (HTML / CSS / JavaScript) بلا أي اعتماديات، يعمل مباشرة على GitHub Pages.

## الرابط

بعد دمج الفرع في `main` يصبح الموقع متاحًا على: `https://khafet.com/kanaf/`

## ما الذي تحتاج تعديله قبل النشر

1. **رقم الواتساب**: ابحث في `index.html` عن `966500000000` واستبدله برقمك بالصيغة الدولية بدون `+` أو أصفار (مثال: `9665xxxxxxxx`). واستبدل أيضًا النص الظاهر `+966 50 000 0000` في قسم «تواصل معنا».
2. **رابط خرائط قوقل**: في قسم الحجز، ضع رابط الموقع في `href` الخاص برابط «افتح في خرائط قوقل». الروابط الفارغة تُخفى تلقائيًا، وتظهر فور تعبئتها.
3. **روابط جاذر وAirbnb**: في بطاقة «متوفر أيضًا على» ضع روابط إعلاناتك. تبقى البطاقة مخفية حتى تعبئة رابط واحد على الأقل.
4. **حسابات التواصل**: في الفوتر (إنستغرام، سناب شات، تيك توك).
5. **أوقات الدخول والمغادرة** والنصوص التسويقية: كلها في `index.html`.
6. **الصور**: في مجلد `images/`. استبدل أي صورة بنفس الاسم (المقاس المفضل 1200×1600). صورة `og-kanaf.jpg` تظهر عند مشاركة الرابط في واتساب وتويتر.

## الهيكل

| الملف | الوظيفة |
| --- | --- |
| `index.html` | الصفحة كاملة (الواجهة، عن كنف، المساحات، المميزات، المعرض، الحجز) |
| `css/style.css` | التنسيقات والاستجابة للجوال |
| `js/main.js` | القائمة، حركات الظهور، عارض الصور، نموذج الحجز عبر واتساب |
| `images/` | صور الشاليه |
| `favicon.svg` | أيقونة التبويب |

## المعاينة محليًا

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080/kanaf/` في المتصفح.

## دومين مستقل

لو أردت للشاليه دومينًا خاصًا (مثل `kanaf.sa`)، انقل محتويات هذا المجلد إلى مستودع مستقل وأضف ملف `CNAME` يحوي الدومين، ثم فعّل GitHub Pages من إعدادات المستودع.
