# OneClick · لوحة الفريق التفاعلية

نسخة احترافية من لوحة «OneClick» التي كانت في إكسل، كموقع ويب كامل يعمل فعليًا:
ثمانية أقسام (فريقي، المخزون، التقويم، الطباعة ثلاثية الأبعاد، المركبات، إنجاز الأسبوع، تسليم الوردية، الابتكار)
مع خلفية ثلاثية الأبعاد متحركة، وواجهة عربية/إنجليزية، وسمة داكنة/فاتحة.

## التشغيل

- **محليًا:** افتح `oneclick/index.html` مباشرة في المتصفح (Chrome أو Edge). لا يحتاج تثبيت ولا خادم ولا إنترنت.
- **على GitHub Pages:** بعد دمج الفرع في `main` تكون اللوحة على `https://khafet.com/oneclick/`.
- **على شبكة العمل الداخلية:** انسخ مجلد `oneclick` كاملًا إلى أي مجلد مشترك أو خادم ويب داخلي.

## أين تُحفظ البيانات؟

كل البيانات تُحفظ في متصفحك (`localStorage`) ولا تُرسل لأي خادم.
من **الإعدادات** تقدر تصدّر نسخة احتياطية (ملف JSON) وتستوردها على جهاز آخر أو تشاركها مع الفريق،
وتقدر ترجع للبيانات التجريبية أو تبدأ من الصفر.

## الأقسام

| القسم | ما يقدمه |
|---|---|
| فريقي | قائمة الفريق، الحالة (على رأس العمل / خارج الدوام / إجازة / تدريب)، الوردية، البحث، تصدير CSV |
| المخزون | الكمية مقابل الحد الأدنى، زيادة/إنقاص سريع، تنبيهات نفاد، فلاتر، تصدير CSV |
| التقويم | شبكة شهرية، أحداث مصنفة (اجتماع/صيانة/تدريب/سلامة)، قائمة القادم |
| الطباعة ثلاثية الأبعاد | لوحة كانبان (انتظار → طباعة → منجز/فشل) بالسحب والإفلات، شريط تقدم، أولوية |
| المركبات | استلام وتسليم مع العداد، صيانة، تنبيه مواعيد الخدمة |
| إنجاز الأسبوع | مهام الأسبوع (بترقيم ISO) تحرّك المؤشر، ترحيل غير المنجز للأسبوع التالي، نسبة كل مسؤول |
| تسليم الوردية | سجل التسليم، مسائل مفتوحة تبقى ظاهرة حتى تُحل، نسخ كنص للإيميل |
| الابتكار | أفكار مع تصويت ومسار مراجعة (جديدة → مراجعة → معتمدة → منفّذة) |

## الاختصارات

`/` للبحث · `1`–`8` فتح قسم · `H` الرئيسية · `Esc` إغلاق النافذة

## البنية

```
oneclick/
├── index.html          الهيكل
├── css/app.css         التصميم (متغيرات الألوان، السمة الفاتحة، الاستجابة للجوال)
└── js/
    ├── i18n.js         الترجمة عربي/إنجليزي
    ├── store.js        الحفظ المحلي + البيانات التجريبية + حساب الأسابيع
    ├── ui.js           المكونات: أيقونات، نوافذ، نماذج، تنبيهات، CSV، المؤشر
    ├── bg3d.js         الخلفية ثلاثية الأبعاد (Canvas بدون مكتبات)
    ├── app.js          الهيكل العام والتنقل
    └── modules/        وحدة لكل قسم
```

بدون أي مكتبات خارجية؛ الخطوط فقط من Google Fonts مع بديل تلقائي عند انقطاع الإنترنت.
